EXECUTIVE SUMMARY & PROBLEM STATEMENT

The retail client faced fragmented sales reporting across multiple regional databases, making real-time margin tracking and store performance comparison nearly impossible for executives.

I engineered an end-to-end analytics workflow: extracting multi-table transactional data using PostgreSQL queries, modeling star-schema relationships in Power BI, and writing DAX measures for dynamic MoM growth tracking.

SQL QUERY & DAX MEASURE HIGHLIGHT

Sample SQL query used for customer cohort revenue aggregation and DAX metric formulation:

SELECT c.customer_segment, DATE_TRUNC('month', s.order_date) AS order_month, SUM(s.sales_amount) AS total_revenue, COUNT(DISTINCT s.order_id) AS order_volume, SUM(s.profit_margin) / SUM(s.sales_amount) AS margin_ratio FROM retail_sales s JOIN customer_dim c ON s.customer_id = c.customer_id WHERE s.order_date >= '2025-01-01' GROUP BY 1, 2 ORDER BY order_month DESC, total_revenue DESC;
